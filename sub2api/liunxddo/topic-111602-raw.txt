这就是原版或者说用的最多deepl服务，目前论坛抓的接口也都是抓的通过这个项目搭建的服务，因为这个服务会向外暴露一个根路径的 GET 路由，返回固定的响应

```css
{
    "code":    200,
    "message": "DeepL Free API, Developed by sjlleo and missuo. Go to /translate with POST. http://github.com/OwO-Network/DeepLX",
}
```
[github.com](https://github.com/OwO-Network/DeepLX/blob/93a3204eab4366b467ac6e2672b0f6186d435837/main.go#L77-L83)
#### [OwO-Network/DeepLX/blob/93a3204eab4366b467ac6e2672b0f6186d435837/main.go#L77-L83](https://github.com/OwO-Network/DeepLX/blob/93a3204eab4366b467ac6e2672b0f6186d435837/main.go#L77-L83)

```go
// Defining the root endpoint which returns the project details
          	r.GET("/", func(c *gin.Context) {
          		c.JSON(http.StatusOK, gin.H{
          			"code":    http.StatusOK,
          			"message": "DeepL Free API, Developed by sjlleo and missuo. Go to /translate with POST. http://github.com/OwO-Network/DeepLX",
          		})
          	})
```

所以都可以用测绘工具扫到公网上搭建了这个deeplx服务的服务器，以此拿来使用 ![Image 35: :face_in_clouds:](https://linux.do/images/emoji/twemoji/face_in_clouds.png?v=12)
